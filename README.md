# Web-Based College Management System

Academic project built with **Java 17**, **Spring Boot**, **Maven**, **MySQL**, **Thymeleaf**, and **Bootstrap 5**.

## Prerequisites
- Java 17 (JDK)
- Maven 3.8+
- MySQL 8.x running on `localhost:3306`

## Setup & Run
1. Update MySQL username/password in `src/main/resources/application.properties` if needed (default: `root` / `root`).
2. Run the application:
   ```bash
   mvn spring-boot:run
   ```
3. Open `http://localhost:8080` in your browser.
4. Login with default Admin credentials:
   - **Username:** `admin`
   - **Password:** `admin123`
